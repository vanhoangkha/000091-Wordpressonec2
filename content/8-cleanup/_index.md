#### Clean up resources

1. CodeDeploy Application

- Go to [CodeDeploy](https://console.aws.amazon.com/codedeploy).

- Select **WordPress_App**.

- Select **Delete application**.

2. EC2 Instances

- Go to [EC2](https://console.aws.amazon.com/ec2).

- Select CodeDeployDemo instance.

- Select **Terminate**.

3. S3 Bucket

- Go to [S3](https://console.aws.amazon.com/s3).

- Select S3 bucket related to the lab.

- Select **Empty**

- Then execute **Delete**.
