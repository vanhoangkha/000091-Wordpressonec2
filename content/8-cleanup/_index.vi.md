#### Dọn dẹp tài nguyên

1. CodeDeploy Application

- Truy cập [CodeDeploy](https://console.aws.amazon.com/codedeploy).

- Chọn **WordPress_App**.

- Chọn **Delete application**.

2. EC2 Instances

- Truy cập vào [EC2](https://console.aws.amazon.com/ec2).

- Chọn CodeDeployDemo instance.

- Chọn **Terminate**.

3. S3 Bucket

- Truy cập [S3](https://console.aws.amazon.com/s3).

- Chọn S3 bucket liên quan bài lab.

- Chọn **Empty**

- Sau đó thực hiện **Delete**.
